# Robot — maze search & genetic algorithms (C#)

Windows Forms app that runs pathfinding and genetic algorithms in a maze.

## Algorithms

- BFS, DFS
- UCS, Greedy, A*
- Genetic Algorithm (GA)

## Tech

- C# / .NET Windows Forms
- Visual Studio solution: `Ai_Prog_One_Search_Strategies_Algorithms_IN_Map.sln`

## Projects in repo

- `Ai_Prog_One_Search_Strategies_Algorithms_IN_Map` — classical search strategies
- `Ai_Prog_Two_Genetic_Algorithm` / `GA` — genetic algorithm variants

## Run

Open the `.sln` in Visual Studio and run the desired project.
